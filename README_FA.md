# Miku Hana Keyboard 🎀

پروژهٔ اولیهٔ کیبورد اندرویدی انیمه‌ای با نام Miku Hana Keyboard.

## امکانات نسخهٔ اولیه
- کیبورد سیستمی اندروید (Input Method Service)
- صفحهٔ اصلی با سه حرف «ه»، «ا»، «پ»
- ردیف ایموجی‌های اخیر (با انتخاب ایموجی، آن ایموجی به ابتدای فهرست می‌رود)
- ذخیرهٔ محلی کلمات و جمله‌های آماده و نمایش آن‌ها در نوار پیشنهادها
- صفحهٔ تنظیمات برای افزودن/حذف کلمات و جمله‌ها
- صفحهٔ اعداد و علائم ساده
- ظاهر صورتی/بنفش و الهام‌گرفته از انیمه

## نکتهٔ مهم دربارهٔ کامل بودن
این یک **پروژهٔ منبع اولیه** است، نه APK کامپایل‌شده. در این محیط ابزار Android SDK/Gradle برای ساخت و امضای APK نصب نبود؛ بنابراین نمی‌توانم صادقانه بگویم APK آمادهٔ نصب ساخته شده است.
همچنین پیشنهادهای خودکار در این نمونه ساده هستند؛ یادگیری زبان فارسی، پیش‌بینی هوشمند جمله و تغییر چیدمان کاملاً پویا به توسعه و آزمایش بیشتر نیاز دارد.

## ساخت APK
1. فایل ZIP را روی کامپیوتر باز کنید.
2. پروژه را با Android Studio باز کنید.
3. اجازه دهید Gradle همگام‌سازی شود و SDK Platform 35 نصب باشد.
4. از منوی **Build > Build APK(s)** استفاده کنید.
5. APK خروجی را روی گوشی اندرویدی نصب کنید.
6. برنامه را باز کنید و از بخش «فعال‌سازی کیبورد»، Miku Hana Keyboard را فعال و انتخاب کنید.

## نکات حریم خصوصی
این پروژه هیچ مجوز اینترنتی درخواست نمی‌کند. کیبوردها به محتوایی که تایپ می‌کنی دسترسی دارند؛ فقط کیبوردی را فعال کن که به کد و سازنده‌اش اعتماد داری. کلمات سفارشی و ایموجی‌های اخیر این نمونه در SharedPreferences محلی ذخیره می‌شوند.
